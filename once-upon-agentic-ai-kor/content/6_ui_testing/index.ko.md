## 🌐 신비한 포털: SSH 터널링

게임 마스터가 현재 여러분의 기계의 로컬 영역에 거주하고 있으므로, 더 넓은 인터넷에서 접근 가능하게 만들기 위해 마법적 다리를 만들어야 합니다. 웹 인터페이스는 보안 마법을 위해 HTTPS 연결이 필요하므로, 이 안전한 통로를 만들기 위해 SSH 터널링을 사용할 것입니다.

### 1단계: 포털 열기 🚪

프로젝트 폴더에서 안전한 터널을 만들기 위해 이 주문을 시전하세요:

```bash
ssh -R 80:0.0.0.0:8009 nokey@localhost.run
```

이 강력한 주문은 다음을 수행할 것입니다:

- **생성** 인터넷에서 로컬 기계로의 안전한 터널
- **제공** 고유한 HTTPS URL
- **리디렉션** 포트 8009에서 실행 중인 게임 마스터로의 모든 트래픽

다음과 같은 신비한 응답을 보게 될 것입니다:

## 🚨 포털 문제 해결

**"Connection Refused" 오류:**

- 로컬 에이전트가 포트 8009에서 실행 중인지 확인
- SSH 터널이 활성화되어 있는지 확인
- 방화벽이 연결을 차단하지 않는지 확인

**"Invalid Server URL" 메시지:**

- 터널에서 HTTPS URL을 사용하고 있는지 확인
- URL 입력에 오타가 없는지 확인
- 터널 연결을 새로고침해보세요

**느린 응답 시간:**

- 로컬 기계의 리소스 사용량 모니터링
- 인터넷 연결 안정성 확인
- 에이전트의 모델 구성을 최적화하는 것을 고려
