## 🎯 퀘스트 목표

전설적인 **운명의 주사위**를 단조하여 맞춤형 도구 생성의 기술을 마스터하세요 - 자존심 있는 던전 마스터에게 필수적인 도구입니다. `3_custom_tools/agent_with_dice_roll_tool.py`의 간단한 주사위 굴리기 함수를 에이전트가 호출할 수 있는 마법 도구로 변환할 것입니다.

## 🔮 맞춤형 도구의 철학

Strands에서 맞춤형 도구는 특별한 마법으로 축복받은 Python 함수일 뿐입니다:

- **🎭 `@tool` 데코레이터**: 일반 함수를 에이전트 도구로 변환하는 마법 룬
- **📜 신성한 독스트링**: 에이전트가 언제, 어떻게 도구를 사용할지 안내하는 설명

## 🎲 챌린지: 운명의 여신과 능력 점수

에이전트 **운명의 여신**은 복잡한 D&D 캐릭터 생성 퀘스트에 도전받을 것입니다:

**퀘스트**: "새로운 D&D 캐릭터를 만드는 것을 도와주세요! 4d6 최저값 제거 방법을 사용하여 힘, 지혜, 카리스마, 지능 능력 점수를 굴려주세요."

**에이전트가 달성해야 할 것:**
1. **이해** 전통적인 4d6 최저값 제거 방법
2. **사용** `roll_dice` 도구를 반복적이고 지능적으로
3. **계산** 각 능력에 대한 최종 점수
4. **제시** 연극적 기교로 결과

[문서](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/tools/tools_overview/#building-loading-tools)에 링크

5. **제시** 연극적 드라마로 결과
