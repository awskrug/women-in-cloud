## Amazon Bedrock 정리

이 워크샵은 주로 Amazon Bedrock을 사용하므로 Bedrock 서비스 자체에 대한 특별한 정리가 필요하지 않습니다. 하지만 다음을 인식하세요:

1. **Bedrock 모델 사용**: 요금은 사용량(입력/출력 토큰)을 기반으로 합니다. 모델 사용을 중단하면 지속적인 요금이 발생하지 않습니다.

2. **Bedrock 모델 액세스**: 활성화한 모델 액세스는 사용하지 않는 한 요금이 발생하지 않지만 활성 상태로 유지됩니다.

## 로컬 개발 정리

1. **로컬 서버 중지**: 
   - 실행 중인 MCP 서버 중지 (터미널에서 Ctrl+C)
   - 로컬 개발 서버 종료

2. **임시 파일 정리**:
   - 개발 중 생성된 임시 로그 파일 제거
   - 해당하는 경우 캐시된 모델 응답 지우기
